    Orla de graduación
    

            
    
              
              Muestra el menú Orla, los botones de pago bajo el visor y los iconos de orla pagada y recibo impreso. Desactívalo si el centro no ofrece este servicio; los pagos ya registrados se conservan.
            
    

            
    

            
    Impresora de recibos
    

            
    
              
    
                
                
                Impresora térmica para imprimir recibos de pago de orla
              
    

              
    
                
                
    
                  
    Seleccione una impresora para ver su información
    
                
    
              
    

              
    
                
              
    

              
    
                
              
    
            
    

            
    
              
    
                
    No se detectaron impresoras mediante la API de Electron.
    
                
    La aplicación utilizará el cuadro de diálogo del sistema de Windows para seleccionar la impresora al imprimir recibos.
    
                
    No es necesaria ninguna configuración adicional.

    Exportación de imágenes
    
            
    Lo que aparece al abrir el cuadro de opciones de las exportaciones de fotos. En cada exportación puedes cambiarlo sin que se guarde aquí.
    

            
    
              
              
              
            
    

            
    
              
              
              Las fotos más grandes se reducen hasta caber en un cuadrado de este lado; las más pequeñas no se amplían. Entre 100 y 4000.
            
    

            
    
              
              
              Se baja la calidad para no pasar de este peso, aunque nunca por debajo de un mínimo razonable. Entre 50 y 5000.
